# AngkutinAja
AngkutinAja adalah aplikasi Android yang dibuat untuk membantu proses pengangkutan sampah dengan menghubungkan pengguna dan petugas.
Aplikasi ini menyediakan fitur login, jadwal pengangkutan (schedule), lokasi, dan contact agar pengguna dan petugas dapat saling terhubung dan
mempermudah proses pengangkutan sampah.
Aplikasi ini memiliki dua sisi pengguna, yaitu **User** dan **Petugas**, dengan fitur yang disesuaikan dengan kebutuhan masing-masing.
Project ini dibuat menggunakan **Android Studio** dan bahasa pemrograman **Kotlin**.
